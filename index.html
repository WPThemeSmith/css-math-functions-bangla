দেখে শিখি, করে শিখি

calc(), min(), max(), clamp() থেকে শুরু করে trigonometric ও exponential function—প্রতিটির expression বদলে live preview দেখুন। প্রতিটি preview-র জন্য slider দিয়ে mobile, tablet বা desktop viewport বেছে নিন।

ব্যবহার করার নিয়ম

প্রথমে category tab, তারপর function tab বেছে নিন। একবারে একটি function-এর editor, viewport slider ও বড় live preview দেখা যাবে। Preview-টি embedded frame-এ চলে, তাই সেখানে vw নির্বাচিত viewport width অনুযায়ী হিসাব হয়। বড় width দেখতে প্রয়োজন হলে preview-র নিচে আড়াআড়ি scroll করুন।

Browser support: CSS math function-গুলোর সমর্থন browser ও version অনুযায়ী আলাদা হতে পারে। কোনো function আপনার browser-এ না চললে সেই preview-তে unsupported/invalid status দেখাবে; অন্য function-গুলো পরীক্ষা করা যাবে। এই পেজে কোনো external library বা network resource লাগে না।

মনে রাখুন: + ও --এর আগে-পরে space দিন। উদাহরণ: calc(100% - 24px)। expression বদলানোর পর browser-এর computed style-ও preview-তে দেখা যায়।
